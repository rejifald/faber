# Docs

- [`adrs/`](adrs/): the decision records, one per decision, numbered in order.
- [`design/`](design/): the design guidelines and the anatomy of each surface.
- The other files here each describe one subsystem or procedure.

An issue or pull request number written as `#123` in these files, in the ADRs or
in a code comment, from before the code came into this repository, refers to its
earlier private repository, `rejifald/faber-legacy`, not to this one.
[ADR-0031](adrs/0031-releases-are-signed-by-github-from-a-fresh-public-repository.md)'s
2026-11-03 amendment says why.
